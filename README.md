# Java OOP and System Design Explorations

This repository is a collection of Java projects created to explore Object-Oriented Programming (OOP) concepts and apply them to system design.

## About

The main goal of this repository is to practice and demonstrate the implementation of various system designs using Java's OOP principles. Each project represents a small system or a concept implementation.

## Projects

Here are some of the projects included in this repository:

*   **Bank System**: A simple banking system demonstrating classes, objects, and encapsulation. (`Bank_with_class.java`, `bank.java`)
*   **Food Delivery System**: A simulation of a food delivery service. (`Food_delivery_system.java`)
*   **Library Management**: A system to manage books and library members. (`Library_management.java`)
*   **Ticket Booking System**: A simple ticket booking application. (`Ticket_Booking.java`)
*   **Inheritance Demo**: Examples illustrating the concept of inheritance in Java. (`inheritance.java`)
*   **Class and Object Examples**: Basic examples of classes and objects. (`class_and_obj.java`)
*   **Data Structures**: Implementation of data structures like Linked Lists. (`Tharavu amaipugal maanakumurai/Linkedlist.java`)
